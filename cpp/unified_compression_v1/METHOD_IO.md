# Unified compression method inventory

Every enabled method accepts the same `Column` envelope: `dtype`, `row_count`, compact little-endian valid numeric bytes, and a 1=NULL bitmap. Compression returns a self-contained UCC1 binary frame plus complete-frame bytes / valid numeric bytes (lower is better), encode time, decode time, and a bit-exact result. A null ratio means that the column contains no valid numeric bytes.

Disabled or unavailable rows remain visible for provenance and are rejected before codec execution. Per-method restrictions appear in the reason and limitations columns; the final column summarizes the common input and output.

The JSON form of `inventory` is the authoritative machine-readable contract. This table deliberately summarizes it for human review.
