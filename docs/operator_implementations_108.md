## 编码与解码边界

`op.scaling.reference_v1` 不再是当前可选择或可新编码的动作。真正的
Scaling 实现仍保留；删除 Identity 不表示删除算法的浮点缩放步骤。
旧 OPA1、阶段状态和带历史注册表版本的文件仍需要解释该旧动作，
因此保留历史 ID 和只读逆操作，不把后续 ID 前移，也不把旧模型动作
重新标成另一个算子。

当前策略视图使用 `cpp-canonical-127-v2`，图视图使用
`operator-taxonomy-30-v5`。策略保留原 0–126 编号区间，ID 5 退役，
STOP 仍为 127；模型仍需 128 个动作槽。旧 `cpp-canonical-127-v1`
配方须显式迁移，Identity 步骤迁移为空配方，不替换成其他动作。

108 是实现归并目录的数量，不是旧注册表的槽位数，也不是已经逐一证明
可独立执行的 C++ 内核数量。冻结的历史注册表、当前可选择视图、语义流
接口和已接线执行能力分别记录。A111 的分离规则已进入目录，但旧 FastPFor
组合入口尚未迁移为独立 A111 和打包调用；本次只同步删除 A005 的执行资格。

PDF 仍解释其他待进一步拆分或合并的条目，不把尚未确认的归并提前扣除。
STOP、Concat、连续 Split 仍为三种特殊操作，不计入 30 类和 108 项。
